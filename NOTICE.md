# Attribution

FreeAgent is a derivative of ZeroScript Free 1.5.5, originally published by sebattfg at https://github.com/sebattfg/ZeroScript-Free under GPL-3.0-or-later.

The browser provider adapters, MAIN-world chat document/network taps, overlay styling, extension icon, and substantial portions of the browser session/agent loop originate from that project. Upstream history also credits archivealf for macOS/Linux work and javnpa for the idea of additional MCP integrations.

Changes in this derivative: general local tools and persistent state; authenticated WebSocket transport; execution approvals and cancellation; general agent prompt and explicit command parser; simplified controls and pairing popup; new setup scripts, documentation, tests and error handling. Roblox Studio is no longer a required backend.

The name FreeAgent identifies this derivative. No affiliation with the original author, AI providers, OpenClaw or Hermes is implied.
