# Roadmap

## Available in v0.1.3

- [x] General file, terminal and Python tools
- [x] Workspace memory, task notes and Markdown skills
- [x] Token pairing and protected-action approvals
- [x] Persistent Always allow grants and a reset control
- [x] Optional desktop tools and stdio MCP addons
- [x] Automated regression and transport checks

## Areas to improve

- [ ] Validate every adapter against current live provider sessions
- [ ] Publish real task recordings and reproducible examples
- [ ] Broaden desktop and launcher validation across operating systems
- [ ] Improve recovery when chat layouts or upload controls change
- [ ] Make permission and cancellation behavior easier to inspect

These are contributor directions, not release commitments. Scheduling, channels and subagents require separate design work; they are not current features.
